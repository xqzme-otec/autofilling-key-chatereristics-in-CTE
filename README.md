# Автозаполнение ключевых характеристик в СТЕ

Решение кейса хакатона Tender Hack (Казань). Пользователь описывает товар своими словами — с опечатками и неполными
данными, — а сервис:

- исправляет опечатки и неверную раскладку;
- находит подходящие позиции справочника КТРУ (категории: одежда, мебель, инструменты);
- извлекает характеристики, сопоставляет значения и единицы измерения и приводит их к виду КТРУ;
- то, чего нет в КТРУ, берёт из справочника Портала поставщиков или сохраняет как новую характеристику;
- поэтапно сужает список кодов КТРУ, задавая уточняющие вопросы, до одного конечного кода;
- находит ошибки — несуществующие значения, неподходящие единицы, выход за диапазоны, подозрительные значения — и объясняет их.

## Структура

| Путь | Что там |
|---|---|
| `ml/` | ML-пайплайн (`ml/pipeline.py` — точка входа `Pipeline.analyze()`), парсер КТРУ (`ml/data/`) |
| `eval/` | Проверка качества: ручной ввод, метрики на запросах из КТРУ и на карточках Портала |
| `tests/` | Юнит-тесты |
| `scripts/` | Подготовка справочника КТРУ из XML |
| `data/` | Подготовленный справочник КТРУ, словари синонимов; сырые выгрузки (`data/raw/`) в репозиторий не входят |
| `backend/`, `frontend/`, `deployment/` | Сервисы и развёртывание |

## Быстрый старт (ML)

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# словарь Портала (уровень «portal» в иерархии источников характеристик):
# положить Инструменты.xlsx, Мебель.xlsx, Одежда.xlsx в data/raw/supplier_portal/, затем
.venv/bin/python -m ml.portal build

.venv/bin/python -m eval.try          # ввести описание товара и посмотреть разбор по шагам
.venv/bin/python -m pytest -q         # тесты
```

Без словаря Портала пайплайн работает: характеристики вне КТРУ сохраняются как новые (`origin: new`).
При первом запуске скачивается модель `intfloat/multilingual-e5-small` (~470 МБ), видеокарта не нужна.

```python
from ml.pipeline import Pipeline

p = Pipeline()
result = p.analyze("стул ученический, ростовая группа 5, цвет синий")
```

Формат ответа и работа с уточняющими вопросами — в [`ML.md`](ML.md).
